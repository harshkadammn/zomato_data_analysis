# 🍽️ Zomato Data Analytics Project

## 📌 Overview

This project focuses on analyzing Zomato restaurant data to extract meaningful insights about customer preferences, restaurant trends, and pricing patterns. The analysis is performed using Python, with a strong focus on data cleaning, exploratory data analysis (EDA), and visualization.

---

## 📂 Dataset

* Source: Zomato dataset (CSV format)
* Contains information such as:

  * Restaurant names
  * Locations
  * Ratings
  * Cuisines
  * Cost for two
  * Votes

---

## 🛠️ Tools & Technologies

* **Python**
* **Pandas** – Data manipulation
* **NumPy** – Numerical operations
* **Matplotlib** – Data visualization
* **Seaborn** – Advanced visualizations

---

## ⚙️ Project Steps

1. **Data Loading**

   * Imported dataset using Pandas
   * Inspected structure and data types

2. **Data Cleaning**

   * Handled missing values
   * Removed duplicates
   * Converted data types where required

3. **Exploratory Data Analysis (EDA)**

   * Analyzed restaurant ratings and votes
   * Explored cost distribution
   * Identified popular cuisines and locations

4. **Data Visualization**

   * Created bar charts, histograms, and heatmaps
   * Visualized rating distributions
   * Compared cost vs rating trends

---

## 📊 Dashboard / Visual Insights

* Rating distribution across restaurants
* Most popular cuisines and locations
* Relationship between cost and ratings
* Voting patterns of customers

---

## 📈 Results & Insights

* Identified top-performing restaurant categories
* Found trends between pricing and customer ratings
* Highlighted locations with high restaurant density
* Observed customer preferences based on cuisine and cost

## ▶️ How to Run

```bash

```

2. Install dependencies

```bash
pip install pandas numpy matplotlib seaborn
```

3. Run the notebook or Python file

```bash

```

or

```bash
python analysis.py
```
